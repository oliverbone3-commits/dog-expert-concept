# Рядом с собакой — концепция

Рабочая концепция экспертного интернет-магазина для собак в Польше (рабочее название).

- `index.html` — главная: список разделов с версиями и датами.
- `concept.html` — концепция, версия 06: позиционирование, аудитория, продукт, партнёрская сеть и рефералка, контент, лояльность, помощь животным, Корея, экономика, юрлицо, бренд, риски, чекпоинты. Старые ссылки вида `index.html#korea` перенаправляются сюда.
- `checklist.html` — чек-лист запуска, версия 02. Отметки и заметки хранятся в браузере, прогресс можно скачать и загрузить файлом.
- `suppliers.html` — поставщики, версия 04: приоритет и статус переговоров на карточке, оценка команды, сверка с концепцией по наборам, отзывы и популярные товары; поиск, фильтры и сортировка; контакты и письма; выгрузка в CSV и Excel. Поиск, фильтры, сортировка и открытая карточка записываются в адрес страницы, ссылка на карточку — `suppliers.html#s-noble-pet`.
- `suppliers-data.js` — данные о поставщиках, единственный источник: из него строятся страница, CSV и Excel. Поставщиков правим только здесь.
- `economics.html` — экономика, версия 03: главное (остаётся с заказа, заказов для нуля, итог года) с тремя переключателями «а что, если», разбор одного заказа, план по месяцам с графиком и контрольными точками, товары (проходит / на грани / не проходит) со ссылками, налоги по формам бизнеса. Таблицы и все вводные свёрнуты; правки в полях хранятся в браузере.
- `economics-data.js` — цифры для экономики, единственный источник: курсы, допущения, позиции с ценами и ссылками, доли источников, заказы по сценариям, ставки налогов и взносов на 2026 год. Новый прайс вносим только здесь.
- `import.html` — импорт, версия 01: пошлина и НДС, обязанности импортёра и магазина, сравнение импорта через Arena Auto и собственного, вопросы поставщику, агенту и бухгалтеру.
- `site.js` — общая оболочка: меню разделов, оглавление страницы, шапка и подвал. Список страниц, их версии и даты хранятся только здесь, в `SITE`.
- `styles.css` — общие стили: токены (цвета, размеры текста, отступы, скругления) и компоненты (кнопка, поле, меню, панель, метки, таблица).

## Как добавить страницу

1. Скопировать `import.html` как основу, в `<body data-page="…">` указать свой идентификатор.
2. Добавить страницу в `SITE` в `site.js`: заголовок, версия, дата, описание для главной.
3. Разделам, которые должны попасть в оглавление, дать `id` и `data-nav="Короткое название"`.

## Как открыть

Открыть `index.html` в браузере. Меню и оглавление собирает `site.js`, без JavaScript страницы открываются без навигации. Чтобы получить публичную ссылку: Settings → Pages → Deploy from branch → `main` / root.

## Статус

Концепция для обсуждения командой, не действующий магазин и не оферта. Условия рефералки и цифры — предложения для пилота. Юридические и налоговые пункты проверить с бухгалтером.
