# Рядом с собакой — концепция

Рабочая концепция экспертного интернет-магазина для собак в Польше (рабочее название).

- `index.html` — концепция, версия 06: позиционирование, аудитория, продукт, партнёрская сеть и рефералка, контент, лояльность, помощь животным, Корея, экономика, юрлицо, бренд, риски, чекпоинты.
- `checklist.html` — чек-лист запуска, версия 02. Отметки и заметки хранятся в браузере, прогресс можно скачать и загрузить файлом.
- `styles.css` — общие стили.

## Как открыть

Открыть `index.html` в браузере. Чтобы получить публичную ссылку: Settings → Pages → Deploy from branch → `main` / root.

## Статус

Концепция для обсуждения командой, не действующий магазин и не оферта. Условия рефералки и цифры — предложения для пилота. Юридические и налоговые пункты проверить с бухгалтером.
